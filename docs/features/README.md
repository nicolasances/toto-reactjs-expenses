# Features

Documentation of the features of the app: what they do, which backend endpoints they call and how they behave on errors.

| Feature | Description |
|---------|-------------|
| [Dashboard: month totals](dashboard-month-totals.md) | Current month's expenses, (expected) income and (expected) savings on the home screen. The income uses the salary prediction of `toto-ms-expenses` when the salary has not been received yet. |
| [Dashboard: past months chart](dashboard-past-months-chart.md) | Bar chart of the total expenses of the last months, with the incomes as an overlay line. Tapping a bar opens that month in the expenses list. |
| [Expenses list](expenses-list.md) | Expenses and incomes of a month in one list, with a month navigator, category change, consolidation and navigation to the detail. |
